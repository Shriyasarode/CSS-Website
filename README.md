# 🌐 Portfolio Demo Webpage

This is a simple and responsive **portfolio demo webpage** created using **HTML and CSS**.  
The project showcases a basic personal website structure with essential sections commonly used in portfolios.

---

## 📌 Features

- 🏠 **Home Page** – Introduction and welcoming section  
- 👩‍💼 **About Page** – Brief information about skills and background  
- 📞 **Contact Page** – Contact details / form layout  
- 🎨 Clean and modern UI design  
- 📱 Add Styling using CSS  

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the website  
- **CSS3** – Styling and layout 

---

## ✨ Key Highlights

- Beginner-friendly and easy-to-understand code structure  
- Separate pages for better content organization  
- Consistent design across all sections  
- Uses semantic HTML for better readability
  
---

- Hands-on practice with CSS styling and layouts  
- Experience in building a multi-page website  
- Strengthened front-end development fundamentals
